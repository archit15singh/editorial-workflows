# Working in this repository

Read [WORKFLOW.md](WORKFLOW.md) when running an editorial batch.

Run the [architecture improvement loop](ARCHITECTURE.md) for production Python changes, CI workflow changes, or observed friction that crosses a module seam. The loop can conclude with a verified fix, a decision to keep the design, or a deferred issue with evidence. Include the record in the same PR when editing this repository. Use the existing publication and merge authorization for each target.
