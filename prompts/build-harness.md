# Goal prompt · Build an end-to-end engineering blog harness

Build and publish a reusable, inspectable harness that turns a public engineering profile and first-party company material into original, evidence-led blog posts. Reconstruct the useful steps from a prior release, including a topic inventory, primary-source claim ledger, reproducible analysis, figures, a prose edit, a Hugo build, scoped PR delivery, deployment verification, and an iteration log.

Provide a local command that composes a bounded run goal and a deterministic check for rendered and live output. Make the public package portable, with a sample profile, manifest, commands, tests, and a clear publication authorization boundary. Use only public inputs in the public repository.

Dogfood the harness on exactly three distinct posts for the supplied profile. Improve the harness using a failure or gap observed in the run. Publish to the authorized blog using its normal merge flow, verify the merged deployment and public assets, and push the harness and the public run record. Stop after three and ask the operator what to do next.
